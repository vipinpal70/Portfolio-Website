A sleek, modern, and fully responsive developer portfolio designed to showcase my work, skills, and experience. It features smooth animations, a theme toggle, and a clean user interface.

---

## Key Features

-  **Dark/Light Mode** — Easily switch between themes  
-  **Smooth Animations** — Leveraging GSAP and CSS keyframes  
-  **Responsive Design** — Optimized for all screen sizes  
- ️ **Interactive Project Cards** — With tech stack info and GitHub links  
-  **Contact Form** — Built-in form for easy communication  

---

##  Technologies Used

- **Frontend:** HTML5, CSS3 (SCSS), JavaScript  
- **Animations:** GSAP, CSS Keyframes  
- **Design Tools:** Figma  
- **Build Tools:** Git, Webpack  
- **Deployment:** GitHub Pages / Vercel

##  Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/portfolio-website.git
cd portfolio-website
```

### 2. Install dependencies (if applicable):

```bash
npm install
npm start
```

### 🎯 Usage
- Toggle Theme: Click the moon/sun icon to switch between dark and light modes.

- View Projects: Click project cards to see details, tech stacks, and GitHub links.

- Contact Me: Fill the form or use social media links to connect.
